# Andrea Vitiello — Graphic Designer Portfolio

A lightweight static portfolio inspired by the structure of Anurag Hazra's portfolio: Home, About, Projects, Skills and Contact, adapted for Andrea Vitiello's graphic design work.

## Run locally

No build tools are required. Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a repository, ideally `USERNAME.github.io` for a personal site.
2. Upload the contents of this folder to the repository.
3. In **Settings → Pages**, choose the `main` branch as the publishing source.
4. GitHub Pages will publish the static `index.html` site.

Replace the placeholders in `index.html` under Contact with the real email, LinkedIn and GitHub URLs.
